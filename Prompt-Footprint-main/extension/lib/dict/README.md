# Spell-check dictionary (compact English)

PromptFootprint's offline spell checker uses [Typo.js](../vendor/typo.js) with a
Hunspell-format English dictionary.

## Files

| File | Purpose | Size |
|------|---------|------|
| `en_US.aff` | Hunspell affix rules (prefixes/suffixes, REP table, TRY order) | ~3 KB |
| `en_US.dic` | ~49.5k base English words (affixes expand these at load) | ~540 KB |
| `dictionary-en.LICENSE` | Upstream license text | — |

This is the **compact** tier: ~49.5k base words (inflected forms are generated
from the affix rules at load), which keeps the bundle to ~540 KB while covering
everyday English. It is intentionally smaller than a full multi-hundred-thousand
word list.

## How it's loaded

The content script fetches these files at runtime via
`chrome.runtime.getURL(...)` (they are listed under `web_accessible_resources`
in `manifest.json`) and constructs `new Typo('en_US', aff, dic)` lazily on first
use. Node tests construct `Typo` directly from a small inline fixture for speed.

## Regenerating / swapping the dictionary

```sh
npm install dictionary-en            # or another dictionary-XX package
cp node_modules/dictionary-en/index.aff extension/lib/dict/en_US.aff
cp node_modules/dictionary-en/index.dic extension/lib/dict/en_US.dic
cp node_modules/dictionary-en/license   extension/lib/dict/dictionary-en.LICENSE
```

Any Hunspell `.aff`/`.dic` pair works; update the filenames in
`extension/lib/spellChecker.js` (`DICT_BASENAME`) and `manifest.json` if you
rename them.
